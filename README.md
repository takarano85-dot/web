# フク Web制作ポートフォリオサイト

大学生フリーランスの「フク」のポートフォリオサイトです。フレームワークなしの素のHTML/CSS/JSで作っています。

## 構成

```
index.html      本体
css/style.css   スタイル
js/main.js      ハンバーガーメニュー、お問い合わせフォームの送信処理
assets/owl.svg  ロゴ・アイコン（Instagramで使っていたフクロウのデザインに合わせています）
```

## ローカルで確認する

ビルド不要です。`index.html` をブラウザで直接開くか、簡易サーバーで確認してください。

```
python3 -m http.server 8000
```

## 公開前に差し替えてほしいところ

- `js/main.js` の `CONTACT_EMAIL`（現在 `your-email@example.com` のプレースホルダー）を実際の連絡先に変更してください。
- お問い合わせフォームは今はバックエンドがないため、送信時にメールソフトを開く簡易実装（mailto）にしています。Googleフォームや外部フォームサービスに差し替えると、より確実に受け取れます。
- `index.html` 内のInstagramリンク（`https://www.instagram.com/`）を実際のアカウントURLに変更してください。
- 料金プラン（スモールサイト¥30,000〜／スタンダード¥80,000〜／オーダーメイド要相談）は、Instagramのハイライト用に以前決めた内容をそのまま使っています。見直し中とのことだったので、金額を変える場合は `index.html` の `#price` セクションを編集してください。
- 「制作実績」「お客様の声」は現時点では準備中のプレースホルダーです。実績が増えてきたら、`#works` / `#voice` セクションに差し替えてください。

## デプロイ

静的ファイルのみなので、GitHub Pages・Netlify・Vercelなど好きなところにそのまま置けます。
